가족과 연결하기

강아지가 본가(가족 집)에 있나요? 가족 폰과 연결하면 가족이 10초 체크를 하고, 다른 게 있는 날만 내 폰에 알림이 와요.

준비물내 폰(이미 멍케어 설치) + 강아지와 같이 사는 가족 폰 1대. 둘 다 로그인(카카오 또는 이메일)이 필요해요. 5분이면 끝나요.
내 폰에서

1앱 처음 등록 때 "가족(본가) 집에 있어요" 고르기

이미 등록했다면 우리 아이 탭 → 메뉴(☰) → 우리 강아지 → "가족 집에 있어요" 스위치를 켜요. 그러면 오늘 화면이 하루 체크 대신 가족 초대로 바뀌어요.

2메뉴(☰) → 계정 → 가족 공유

로그인이 안 돼 있으면 여기서 먼저 로그인해요.

3초대 코드 만들기

[초대 코드 만들기]를 누르면 6자리 코드가 나와요. 가족에게 카톡으로 보내 주세요. 코드는 7일 동안 쓸 수 있어요.

AB12CD예시예요. 실제 코드는 앱에서 만들어요
가족 폰에서

4멍케어 설치하기

가족 폰도 홈 화면에 설치해요. 설치 방법 그림으로 보기 →

5처음 열 때 이름 칸 아래 "가족 초대 코드"에 입력

강아지 이름을 새로 적지 말고, 아래 가족 초대 코드 칸에 받은 코드를 넣고 [가족 강아지와 연결하기]를 눌러요. 로그인 한 번 하면 강아지가 그대로 나타나요.

6가족은 매일 "오늘 나 어땠어?"에 한 번만

평소와 같으면 한 번, 다른 게 있으면 그것만 골라요. 다른 게 있는 날만 내 폰에 "오늘 다른 점: 변 무름" 같은 알림이 와요. 병원 일정·접종 날짜도 같이 보여요.

멍케어 열기 → 연결이 안 되면 오픈채팅으로
가족이 코드를 넣었는데 강아지가 안 보여요

가족 폰도 로그인이 돼 있어야 해요. 로그인 뒤 앱을 완전히 껐다 켜면 몇 초 안에 나타나요.

부모님 폰에 깔아 드리기 어려워요

본가 가실 때 직접 깔아 드리는 게 제일 빨라요. 그 전까지는 병원 일정·접종 알림만 써도 돼요. 매일 안 열어도 괜찮아요.

가족이 이미 다른 폰에서 쓰고 있어요

그 가족 폰의 설정 → 가족 공유에서 코드를 만들고, 내 폰에서 코드를 넣으면 돼요. 방향은 어느 쪽이든 괜찮아요.
