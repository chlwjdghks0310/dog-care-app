멍케어 설치하기

앱스토어가 아니라 홈 화면에 추가해서 써요. 1분이면 끝나요. 그림대로 한 번만 따라 해 주세요.

왜 홈 화면에 설치해야 하나요?아이폰은 홈 화면에 설치한 앱에서만 알림이 오고, 사파리에서 그냥 쓰면 7일 동안 안 열었을 때 기록이 지워질 수 있어요. 설치한 앱은 지워지지 않아요.

꼭 사파리로 열어 주세요. 카카오톡 안에서 열렸다면 오른쪽 아래 ··· → 다른 브라우저로 열기.

1주소창 오른쪽 ••• 누르기

화면 아래 주소창 끝에 점 세 개가 있어요. (옛 아이폰은 아래 가운데 공유 버튼 ⤴을 바로 누르면 2번을 건너뛰어요)

2공유 누르기

메뉴에서 공유를 눌러요.

3아래로 내려 홈 화면에 추가

공유 창의 목록을 아래로 내리면 홈 화면에 추가가 있어요.

4'웹 앱으로 열기'는 켜진 채로, 오른쪽 위 추가

이름은 '멍케어' 그대로 두고 추가를 눌러요.

'웹 앱으로 열기'가 꺼져 있으면 켜 주세요. 꺼진 채로 추가하면 알림이 오지 않아요.

5홈 화면의 멍케어 아이콘으로 열기

이제부터는 사파리가 아니라 이 아이콘으로만 열어 주세요. 처음 열면 우리 아이 이름부터 물어봐요.

크롬으로 열어 주세요. 화면 아래에 [설치] 띠가 보이면 그걸 바로 눌러도 돼요.

1오른쪽 위 ⋮ 누르기

2홈 화면에 추가 (또는 앱 설치)

기기에 따라 이름이 '앱 설치'·'홈 화면에 추가'·'설치 및 바로가기 만들기'로 달라요. 셋 다 같은 거예요.

3설치 누르기

홈 화면에 멍케어 아이콘이 생겨요. 이제 그 아이콘으로 열어 주세요.

삼성 인터넷을 쓰면: 아래 메뉴(≡) → 현재 페이지 추가 → 홈 화면 → 추가.

멍케어 열기 → 설치가 어렵거나 함께 테스트해 주실 분은 오픈채팅으로

막혔을 때

화면을 캡처해서 오픈채팅에 올려 주시면 바로 도와드려요. 이미 앱을 쓰고 계시면 설정(☰) → 의견 보내기로도 돼요.

'홈 화면에 추가'가 안 보여요

카카오톡·인스타그램 안에서 열면 안 보여요. ··· 메뉴에서 '다른 브라우저로 열기'(또는 '외부 브라우저에서 열기')를 누른 뒤 다시 해 주세요.

사파리에서 적은 기록이 설치한 앱에 없어요

아이폰은 사파리와 홈 화면 앱의 저장 공간이 따로예요. 그래서 처음부터 홈 화면 앱에서 시작하는 걸 권해요.

로그인해야 하나요?

아니요. 바로 써요. 로그인은 나중에 설정 → 백업·로그인에서 하면 되고, 하면 폰을 바꿔도 기록이 남아요.
