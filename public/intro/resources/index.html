바로 열기 (새 창) 내려받기

파일이 커서 와이파이에서 여는 걸 권해요. 아이폰은 [바로 열기] 뒤 공유 버튼 → "파일에 저장"으로 보관할 수 있어요.

일반적인 참고 자료예요. 진단·치료는 수의사와 상담하고, 법령·규정은 공식 기관의 최신 정보를 확인해 주세요.

멍케어 앱 받는 법

앱스토어 없이 휴대폰 홈 화면에 설치해서 써요. 지금은 베타라 모든 기능이 무료예요.

아이폰 (사파리)
공유 버튼 → 홈 화면에 추가 → 추가
안드로이드 (크롬)
오른쪽 위 ⋮ → 설치 (기기에 따라 '홈 화면에 추가')
삼성 인터넷
메뉴(≡) → 현재 페이지 추가 → 홈 화면
